Utiliser le système en 5 étapes

Pas besoin d'être technicien. Tu remplis un fichier, tu double-cliques, tu récupères tes annonces.
La seule chose vraiment importante pour toi : remplir le fichier Excel. Le reste, c'est un double-clic.
1

Installer Python (une seule fois)

Va sur python.org, télécharge Python pour Windows, et pendant l'installation coche « Add Python to PATH » (en bas du premier écran). Fait une fois pour toutes.

2

Décompresser le dossier

Clic droit sur medlist_system.zip → Extraire tout → Extraire. Tu obtiens un dossier medlist_pkg.

3

Remplir tes machines

Ouvre output\intake\FICHE_A_REMPLIR.xlsx. Une ligne par machine. Remplis surtout : État, Pays, Année, N° de série, Photos. Les 2 lignes jaunes sont des exemples. Enregistre.

4

Lancer le système

Dans medlist_pkg, double-clique sur RUN_ME.bat. Une fenêtre s'ouvre, travaille, et affiche « DONE ». C'est fini.

5

Récupérer tes fichiers

Ouvre le dossier output. Tu y trouves tes annonces (FR/EN/ES), le fichier eBay à importer, les emails brokers, et le fichier contacts.

Ce que tu fais avec chaque résultat
eBay / DOTmed / Machinio / Kitmondo — importe le fichier .csv / .tsv directement sur la plateforme. automatique
Leboncoin / Wallapop / Facebook — ouvre le texte d'annonce, copie-colle, ajoute les photos, publie. ~2 min chacune. manuel
Brokers / international — ouvre broker_email_READY.txt, ajoute ton numéro + email, envoie.
Photos : sur Leboncoin / Facebook, tu ajoutes les photos directement au moment de publier. Pour eBay / DOTmed, il faut des liens https (héberge-les sur ton site, Google Drive public, ou Imgur), puis colle les liens dans la colonne « Photos ».

Important : le système ne publie pas tout seul sur Leboncoin / Facebook / enchères — c'est interdit et ça fait bannir les comptes. Il te prépare tout ; tu valides et tu publies.
